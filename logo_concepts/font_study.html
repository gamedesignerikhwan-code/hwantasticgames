로고 폰트 검토 — 게임 스택에 맞추기

Minesweeper Extreme에서 실측한 폰트 스택을 기준으로, 카드 그리드 로고에 어떤 게 맞는지 비교. Hearts Extreme는 Vercel 인증(Authentication required)이 걸려 있어 확인 불가 — 같은 스택이라는 전제로 진행했다.

실측 — 게임 사이트가 쓰는 폰트

역할폰트실제 사용
DisplayOutfit 600 / 800 / 900 H1 "MINESWEEPER" — 89.6px, w900, letter-spacing:-1px
Body / UIInter 400 / 600 / 700 / 800 body { font-family: Inter, sans-serif }
MonoFira Code 500 / 600 / 700 로드되어 있으나 랜딩엔 미노출 — 인게임 카운터·타이머로 추정
배경#0f172a 스튜디오 사이트는 #0a0c10 — 통일 필요
현 스튜디오 사이트는 Montserrat(헤딩) + Outfit(본문). Montserrat은 게임 어디에도 안 쓰인다 — 이번에 버리는 게 맞다.

Tier 1 카드 그리드 — 4개 폰트 비교

셀 안에 글자가 낱개로 격리되는 조판이라, 일반적인 로고 폰트 선택 기준과 다르게 봐야 한다.

핵심 — 셀 채움률 편차

모든 셀이 같은 크기인데 글자 폭은 폰트마다 다르다. W는 넘치고 I는 텅 빈다. 아래는 각 폰트로 15글자를 실측(canvas)해 셀 대비 차지하는 비율을 그린 것. 편차가 작을수록 그리드가 고르게 보인다.

결선 — Tier 2 / Tier 3 대조

가로 락업(글자가 붙어 있음)과 아이콘(글자 1개)에서도 확인.

결론

대상폰트이유
로고 (Tier 1·2·3) Fira Code 600 — 대문자만 모노스페이스는 모든 글자 폭이 동일하다. 셀 폭 = 글자 advance 폭이라 그리드와 조판 원리가 일치한다. "결정론·완전정보"라는 게임 컨셉과도 같은 말을 한다. 이미 게임 스택 안에 있어 새 폰트를 추가하지 않는다.
차선 Inter Tight 600 Fira Code의 "개발자 폰트" 뉘앙스가 걸린다면. 중립 그로테스크라 그리드와 안 싸운다. 단 W·I 편차는 트래킹으로 수동 보정 필요.
비추천 Outfit 지오메트릭이라 O·G·S가 정원(正圓)에 가깝다. 사각 셀 안에서 모서리 네 곳이 비어 그리드가 헐거워 보인다. 게임 타이틀 전용으로 남기는 게 맞다.
폐기 Montserrat 게임 어디에도 안 쓰인다. Outfit과 인상이 겹쳐 둘 다 둘 이유가 없다.
