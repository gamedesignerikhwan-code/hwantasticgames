헤븐스 도어 — 전체 규칙서

게임 정보

• 2~4인 / 30분 / 8세 이상 / 드래프트, 세트 컬렉션

구성물

  • 게임 타일 96개: 6종 기호(삼각형·사다리꼴·정사각형·원·별·육각형) × 8종 색상 × 각 2장씩 쌍으로 구성
  • 개인 타일 32개: 플레이어당 8개 (기호별 점수 타일 6개 + 콤보 1개 + 중복 1개)
  • 개인 보드 4개: 가로형 보드, 기호별 슬롯 및 세트 점수 트랙

피라미드 적재 셋업

  • 2인 게임: 2개 층 (1층 6×5=30개 / 2층 5×4=20개)
  • 3인 게임: 2개 층 (1층 7×6=42개 / 2층 6×5=30개)
  • 4인 게임: 3개 층 (1층 7×6 / 2층 6×5 / 3층 5×4)
  • 최상층 타일은 모두 앞면으로 놓으며, 아래층 타일들은 무작위로 앞면 또는 뒷면으로 배치합니다.

타일 획득 조건

자신의 차례에 조건을 만족하는 타일 2장을 가져옵니다. 두 타일은 반드시 색상이 일치하거나 기호가 일치해야 합니다.

획득 가능한 타일이란?

  1. 앞면이 노출되어 있어야 합니다 (위층 타일에 덮여 있지 않아야 함).
  2. 적어도 한 쪽 변이 외곽에 노출되어 있어야 합니다 (해당 층에서 상·하·좌·우 4방향이 모두 다른 타일로 둘러싸인 내부 타일은 가져올 수 없습니다).
  3. 게임 중 타일을 가져와 아래층의 뒷면 타일이 완전히 드러나면, 즉시 앞면으로 뒤집습니다.

개인 보드 배치 순서

가져온 타일은 기호가 처음 획득된 순서대로 개인 보드의 왼쪽에서 오른쪽 열에 차례로 배치됩니다. 같은 색상의 타일을 하나의 기호 더미에 중복으로 올릴 수 없습니다.

[COMBO] 콤보 규칙

한 차례에 색상과 기호가 완전히 동일한 2장을 가져오면 [COMBO]가 발생합니다! 1장은 정상적으로 개인 보드 기호 열에 놓고, 나머지 1장은 별도의 [COMBO] 타일 아래에 놓습니다. (게임 종료 시 장당 7점!)

[DUPLICATE] 중복 타일

이미 보유한 기호 더미에 있는 색상과 동일한 타일을 가져오면, 그 타일은 더미 위에 올리지 못하고 [DUPLICATE] 타일 아래에 놓습니다. (게임 종료 시 장당 2점)

게임 종료 및 최종 점수

모든 플레이어가 10턴을 마치면(각자 총 20장 획득) 게임이 종료됩니다.

합산 점수 항목

  1. 기호별 점수: 6종 기호 점수 합계
  2. 세트 컬렉션 보너스: 수집한 기호 종류 수에 따라 보너스 (1종: 0 / 2종: 0 / 3종: 0 / 4종: 5 / 5종: 15 / 6종: 30 pt)
  3. [COMBO] 점수: 콤보 타일 1장당 7 pt
  4. [DUPLICATE] 점수: 중복 타일 1장당 2 pt

첫 배치 순서 결정

새로운 두 종류의 기호가 동시에 획득되었습니다. 개인 보드의 왼쪽에 먼저 놓을 기호를 선택하세요.
